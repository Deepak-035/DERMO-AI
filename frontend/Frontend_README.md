# DERMO-AI Frontend — Automated Skin Disease Classification System

A next-generation automated skin disease classification web application powered by a **Hybrid CNN-Transformer** deep learning model (PyTorch), a **FastAPI** backend, and a modern **React 19 + TypeScript + Vite** glassmorphic frontend.

---

## 🚀 Key Features

- **Sequential 3-Stage Classification**:
  - Stage 1: MobileNetV2 skin vs. non-skin validation.
  - Stage 2: EfficientNetB0 normal vs. lesion-affected skin detection.
  - Stage 3: Hybrid CNN–Transformer 7-class lesion disease classification (`nv`, `mel`, `bkl`, `bcc`, `akiec`, `vasc`, `df`).
- **Dynamic Skin Condition Educational Guide**:
  - Real-time educational guidance rendered beneath the result card upon completed prediction.
  - Interactive accordions covering condition overviews, statistical risk factors, warning signs, prevention, medical next steps, clinician-directed treatment options, and medical citations.
  - Distinct urgency badges (`Routine`, `Prompt`, `Urgent`) and non-diagnostic safety disclaimers.
- **Clinical Assessment PDF Reports**:
  - Downloadable PDF reports generated by ReportLab on the backend.
  - Strict isolation: educational guides appear only in the web UI and do not alter or appear in PDF reports.
- **Two-Role Authentication & Access Control (RBAC)**:
  - User and Admin role segregation with Supabase Row Level Security (RLS).
  - Private screening history management with delete capabilities.
  - Administrative console with system activity graphs and diagnosis breakdown.
- **Live Health Monitoring**: Real-time connection status between the React frontend and FastAPI backend.

## ⚡ Quick Start

### 1. Configure Environment
Copy `.env.example` to `.env`:
```env
VITE_API_URL=http://localhost:8000
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 2. Install Dependencies
```powershell
cd frontend
npm install
```

### 3. Launch Development Server
```powershell
npm run dev
```

Open your browser at **http://localhost:5173** to launch DERMO-AI!
